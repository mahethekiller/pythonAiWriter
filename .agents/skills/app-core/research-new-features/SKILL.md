# Feature Research & Product Discovery Skill (`research-new-features`)

This skill governs feature research, market analysis, competitor auditing, and product roadmap planning for the **PythonAiWriter** desktop application.

## 🎯 Research Methodology

1. **Competitor Auditing**:
   - Compare application capabilities against leading content & SEO tools:
     - **SurferSEO / Clearscope / MarketMuse**: Content score algorithms, NLP keyword density, heading distribution, SERP analysis.
     - **Jasper / Copy.ai**: Strategy presets, brand voice, prompt customization.
     - **Cursor IDE**: Modern desktop UI, split-screen live previews, instant preset switching.

2. **Technical Feasibility Assessment**:
   - Evaluate proposed features against the current tech stack:
     - **Core Backend**: Python 3.10+, `requests`, `BeautifulSoup4`, `pandas`, `python-docx`.
     - **AI LLM APIs**: OpenAI (GPT-4o, o1), Gemini 2.0 Flash, Claude 3.5 Sonnet, DeepSeek, Groq, Ollama.
     - **Desktop UI**: CustomTkinter native Dark/Light mode theme system.

3. **Output Standardization**:
   - Synthesize research findings into `analysis_results.md` artifacts containing:
     - **Executive Summary**
     - **Mermaid Flowcharts & System Diagrams**
     - **Detailed Feature Breakdown**
     - **Priority Matrix (Impact vs. Effort)**

---

## 📋 Research Focus Areas

- **AI & Content Intelligence**: Plagiarism detection, AI humanizers, real-time SERP outline scrapers, sitemap link miners.
- **Publishing & Workflows**: Direct WordPress/Shopify/Ghost REST API integration, scheduled batch queue runner.
- **SEO & Schema**: JSON-LD Schema.org generators, Flesch reading ease scoring, keyword density auditing.
- **UI / UX Excellence**: Split-screen WYSIWYG editors, 1-click ZIP export bundlers, hardware-accelerated preview cards.
